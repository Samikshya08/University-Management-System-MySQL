University Management System:
A menu-driven University Management System built using Java, MySQL, and JDBC.

Features:
Student Record Management (CRUD Operations)
Instructor Information Management
Course Enrollment Tracking
Salary Processing (HRA & TDS)
Database Connectivity using JDBC

Tech Stack:
- Java
- MySQL
- JDBC
- SQL

Project Structure:
├── main.java ├── README.md

How to Run:
1. Create the required MySQL database.
2. Configure the JDBC connection details.
3. Compile and run the Java program.
